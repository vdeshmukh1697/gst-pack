# GST Pack for Shopify

The built try-it-yourself page: a Shopify order export in, a month's GST
invoices, GSTR-1 file and Tally import out, made entirely in the browser.

This repository holds only the built page, served by GitHub Pages. Nothing
here runs on a server, and the page's Content-Security-Policy forbids it from
connecting anywhere, so a merchant's orders stay on their own computer.
